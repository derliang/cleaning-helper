# 掃地工作小幫手：設計規範

> 狀態：定案（v2.12 改版）。最後更新：2026-10-25。改任何頁面、版面、元件、樣式前先讀這份。要偏離，先更新本文件並取得使用者確認。

- 定案的模擬頁：[docs/design/mockups/抽籤工作台.html](mockups/抽籤工作台.html)（手機、iPad、桌機；開啟後可用右上角切換深淺色）
- 規範的實際樣式在 `index.html` 最上方 `<style>`：`:root` 是 tokens，其後是元件。本文件是它的說明，兩者不一致時以使用者確認過的本文件為準，並修正程式。
- 範圍：只改視覺與版面，功能與資料流程不動。
- 這份規範只管這個程式，不做跨程式共用的元件庫。

## 1. 設計原則

1. **抽籤是主角。** 「抽全部」是整個畫面唯一的實心主色大按鈕；匯出、備份等次要動作一律用次要按鈕，只靠小色點區分。因為老師開啟程式幾乎只為了抽籤。
2. **淺色是紙本點名簿，深色是教室黑板。** 淺色用暖白紙底，深色用藍黑底。兩套各自調過，不是互相反相。
3. **琥珀色只代表兩件事：辛苦的工作、抽籤進行中。** 其他地方不用，這樣一眼就找得到辛苦的工作。
4. **手機與 iPad 先考慮拇指。** 點擊區 ≥ 44px；最常按的抽籤按鈕固定在底部頁籤列上方。
5. **介面圖示一律 emoji。** 工作項目由使用者自己選的 emoji 是資料，不要改。

## 2. Tokens

全部用 `#RRGGBB`。不要用 `oklch()`、`color-mix()`：html2canvas 無法解析，匯出圖片會失敗。

對比（已用程式計算）：上述文字配對在淺色、深色都 ≥ 4.9:1，主色按鈕 5.4 以上。新增色票時一併驗證。

### 間距、圓角、陰影、動態

- 圓角：`--r-sm` 8、`--r-md` 12、`--r-lg` 16、`--r-xl` 22。按鈕與輸入框用 md，卡片用 lg，彈窗與主要動作區用 xl。
- 陰影：`--shadow-1` 用在卡片，`--shadow-2` 用在彈窗與「抽籤中」的卡片。深色以邊線分層為主，陰影很輕。
- 間距：4 的倍數；頁面內區塊間距 20（桌機 24），卡片內距 14–20。
- 動態：只用在狀態變化（懸停、按下、彈窗滑入、提示訊息淡入）。抽籤動畫是功能，保留原本六種。

## 3. 版面與斷點

斷點用 `min-width`，由手機往上加。

| 寬度 | 導覽 | 抽籤按鈕 | 備註 |
|---|---|---|---|
| < 768（手機） | 頂部窄欄（品牌、深淺色、備份）＋底部頁籤列（5 個，emoji＋短名） | 固定在底部頁籤列上方 | 頁面單欄；工作清單變卡片；彈窗是底部滑出的面板 |
| 768–1023（iPad 直向） | 左側窄軌（92px，emoji 在上、短名在下） | 在頁面內 | 名單、工作頁為單欄或雙欄 |
| ≥ 1024（桌機、iPad 橫向） | 左側欄（244px，完整名稱、深淺色切換、備份） | 在頁面內 | 內容最寬 1160px；點擊區縮到 40 / 34 |

頁籤名稱：完整名稱用在側欄與頁面標題（抽籤工作台、名單管理、掃地工作項目、歷史記錄、系統設定），短名用在底部頁籤與窄軌（抽籤、名單、工作、紀錄、設定）。

## 4. 元件規則

- **按鈕** `.btn`：預設（次要）、`btn-primary`（主要，一個畫面只放一個大的）、`btn-accent`（抽一人）、`btn-soft`、`btn-danger`（刪除類，淡紅底）、`btn-ghost`（無框）。尺寸 `btn-lg`（56）、預設（手機 44／桌機 40）、`btn-sm`（手機 44／桌機 34）、`btn-icon`（正方形）。停用時透明度 .45。
- **匯出按鈕** `.xbtn`：次要按鈕＋右上角（桌機在右側）品牌色小點：LINE `#06C755`、PNG `#0284c7`、PDF `#E1251B`、Excel `#107C41`、Word `#185ABD`。手機上五顆排成一列，emoji 在上。
- **座號名牌** `.tag`：左側實心主色方塊放兩位數座號，右側姓名。指定（手動）用靛色 `.tag-manual` 並加「指定」小標；空缺 `.tag-empty` 虛線；免掃地等純顯示用 `.tag-plain`；抽籤中 `.tag-draw`。
- **工作卡片** `.tcard`：左上圖示方塊（類別色底）、名稱（辛苦的加 🔨）、說明（最多兩行）、右上 🗑️；下方類別標籤「教室 · 2 人」，再下方是人員名牌。辛苦的卡片用 `--heavy-bg` 與琥珀外框；抽籤中的卡片用 `--ring` 光圈並微微上浮。
- **類別標籤** `.badge`、**狀態標籤** `.chip`（`chip-ok`、`chip-warn`、`chip-info`、`chip-danger`）。
- **表單**：`.input`、`.select`、`.textarea` 高度 = 點擊區，焦點時主色外框與淡色光暈。開關用 `input.switch`（原生 checkbox，`v-model` 照舊）。單選一組用 `.seg` 分段控制（`aria-pressed` 表示目前項）。
- **彈窗** `.scrim` ＋ `.modal`：手機是從底部滑出的面板，iPad 以上置中。關閉鈕在右上，點擊區 44。
- **提示訊息** `.toast`：手機在底部操作列上方置中，桌機在右下角。用 `transition name="toast"`。
- **危險動作**：刪除、清空放在次要位置並用 `btn-danger`。「全部重設」只在「系統設定 → 系統維護」，不放在每頁都看得到的地方。

## 5. 頁面規則

| 頁面 | 區塊順序 | 備註 |
|---|---|---|
| 抽籤工作台 | 標題 → 概況（四格合一條） → 抽籤動作（抽一人、抽全部、清除） → 分配表（狀態標籤、匯出列、工作卡片、免掃地成員） | 手機的抽籤動作固定在底部；概況手機 2×2 |
| 名單管理 | 標題與「全部參與抽籤」 → 左：新增與匯入（手機收進可展開區塊） → 右：同學名單 | 同學列：參與開關、座號、姓名、指派、刪除 |
| 掃地工作項目 | 標題、復原、清空 → 左：新增表單（手機收進可展開區塊） → 右：類別篩選、工作列表 | 工作列表桌機是表格式，手機是卡片 |
| 歷史記錄 | 標題、排序 → 每筆可展開的記錄（匯出、刪除、各工作人員、免掃地名單） | |
| 系統設定 | 外觀 → 抽籤偏好 → 工作類別 → 匯出設定 → 備份與還原 → 系統維護（恢復預設、全部重設） | 外觀只存在這台裝置，不進備份 |

模擬頁對應檔：`mockups/抽籤工作台.html`（其餘頁面沿用同一組元件）。

## 6. 文案語氣

台灣繁體中文，直接說會發生什麼。按鈕用動詞（「增加掃地工作項目」「儲存變更」）；錯誤與提示說明原因與下一步；不使用「請注意」「溫馨提醒」之類的墊字。

## 7. 無障礙

- 文字對比 ≥ 4.5:1；手機與 iPad 的點擊區 ≥ 44px；最小字級 12px。
- 只有圖示的按鈕要有 `aria-label`。目前頁用 `aria-current="page"`，開關狀態用 `aria-pressed`。
- 鍵盤焦點一律是 2px 主色外框，不要移除 `:focus-visible`。

## 8. 不要做的事

- 不引入 Tailwind 或其他 CSS 框架；樣式用本文件的 tokens 與元件類別。
- 不寫死色碼、不用漸層背景、不用 `oklch()` 或 `color-mix()`。
- 不用琥珀色表示辛苦與抽籤中以外的事。
- 不在匯出的 PNG、PDF、Excel、Word 內容加入介面樣式或版權句；匯出樣式限定在 `.export-sheet`，永遠是淺色。
- 不把「全部重設」放回每頁都看得到的位置。
- 不另加第二個頁尾；版權句維持在既有 `<footer>`（見 TODO.md 的版權維護規範）。

## 9. 深淺色機制

- 顏色全部由 `:root` 的 tokens 提供。深色在兩處覆寫：`@media (prefers-color-scheme: dark)`（限 `:root:not([data-theme="light"])`）與 `:root[data-theme="dark"]`。
- 外觀有三種：跟隨系統（不設 `data-theme`）、淺色、深色。選擇存在 localStorage 的 `cleaning_helper_theme`，不進備份。
- `<head>` 內有一小段同步程式，在畫面繪製前套用 `data-theme`，所以深色使用者不會先閃一下亮色。
- 升級遷移：沒有 `cleaning_helper_theme` 時，舊資料存過深色的人維持深色，其餘跟隨系統。
