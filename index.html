🚀 如何將本系統部署至 GitHub Pages？

  1. 建立 GitHub 儲存庫 (Repository)

    登入 GitHub，點選「New repository」，取名為 cleaning-helper 並設為 Public。

  2. 上傳專案檔案

    將 index.html 與 README.md 上傳至該 Repository 的主分支 (main)。

  3. 開啟 GitHub Pages 服務

    進到 Repository 的 Settings > Pages > Source 選擇 Deploy from a branch，Branch 選擇 main / root 點擊 Save。

  4. 完成部署！

    幾分鐘後即可透過 https://<your-username>.github.io/cleaning-helper/ 網址公開存取並分享！
