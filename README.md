# 🧹 掃地工作小幫手 (Cleaning Task Helper)

「掃地工作小幫手」是一款專為班級、辦公室、團隊設計的**智慧單頁式靜態網頁抽籤工具 (Single-Page Web App)**。支援靈活的人員管理、掃地工作需求人數設定、多款趣味抽籤動畫特效、避重複機制、LINE 排班文字導出與 5 大官方專屬軟體格式匯出功能。

無需任何伺服器後端或資料庫，所有資料皆完全儲存於您的瀏覽器本機 (LocalStorage) 中，極度重視隱私與個人資訊安全。

---

## 🌟 核心特色 (Core Features)

- 🎲 **多款動態抽籤特效與時長自訂**：
  - 支援 **6 款動畫效果**（🎰 拉霸機姓名高速滾動、🎴 卡片翻牌揭曉、✨ 霓虹光芒閃爍、🎈 開心彈跳登場、🎲 幸運骰子旋轉、⚡ 無動畫極速揭曉）。
  - 可自訂全體總抽籤時長（⏱️ 短 6 秒 / 中 12 秒 / 長 18 秒）。
  - 抽籤完成時觸發爆發彩帶動畫 (Canvas Confetti)。

- 🙏 **雙重抽籤模式**：
  - **🎲 抽全部**：全體成員自動依序抽取填滿所有工作缺額。
  - **🙏 抽一人**：按一次從所有尚有缺額的工作中**純隨機抽選一項**並抽出一名同學，適合老師單人逐一抽籤！

- 🔨 **辛苦工作壓軸抽籤 & 避重複/大風吹機制**：
  - 辛苦的工作 (🔨) 置頂優先呈現，但在全體抽籤時最後壓軸揭曉！
  - 內建 **⚡ 不重複模式**、**🛡️ 不悲情模式**、**🌀 大風吹模式**（確保大分類工作不與上次重複）。

- 📊 **5 大官方代表品牌風格匯出**：
  - 💬 **LINE**：一鍵複製格式化排班文字（直接發送到 LINE / Slack 群組）。
  - 🖼️ **PNG**：生成高畫質排班卡片圖片下載。
  - 📄 **PDF**：完整支援印表機與 PDF 排版列印。
  - 📊 **Excel**：採用 SheetJS 生成真實 `.xlsx` 檔案，支援帶有 B 欄與 E 欄資料驗證下拉選單的範本下載與匯入！
  - 📝 **Word**：一鍵匯出標準 `.doc` 排班文字檔，並支援上傳自訂 Word/Excel 範本。

- 👥 **班級同學名單一頁全顯**：
  - 採用自適應多欄並排網格，**全數移除內部捲軸**，全班同學一次性完整呈現於同一個頁面。
  - 支援批次貼上劃分座號、一鍵切換參與/免掃地、全選/全取消出席。

- 🧹 **掃地工作管理與膳食類關鍵字圖示比對**：
  - 掃地工作列表最左側具備 **1 ~ N 序號編號**，說明文字同列展示。
  - 提供 **✏️ 快速編輯彈窗** 與顯眼紅色 **🗑️ 刪除按鈕**。
  - 智慧關鍵字比對：輸入包含「`搬餐桶`」、「`抬飯`」、「`抬湯`」、「`搬湯`」、「`廚餘`」等關鍵字時，自動套用 **🍱/🍲 餐桶類 Icon**！

- 📜 **歷史紀錄與 JSON 備份還原**：
  - 完整記錄歷次抽籤詳情，支援按座號或工作屬性排序。
  - 支援 JSON 備份檔案之匯出與還原。

## 🛠️ 技術架構

- **前端框架**：[Vue 3](https://vuejs.org/) (SFC Global Build via CDN)
- **UI 樣式**：[Tailwind CSS](https://tailwindcss.com/) (Dark Mode Ready)
- **Excel 處理**：[SheetJS (XLSX)](https://sheetjs.com/)
- **圖片生成**：[html2canvas](https://html2canvas.hertzen.com/)
- **特效元件**：[Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **資料持久化**：Browser LocalStorage API
